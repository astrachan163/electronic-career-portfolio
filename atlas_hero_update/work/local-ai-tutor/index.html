Why on-device

  • Privacy: course PDFs, notes, and chat stay in the app sandbox instead of a hosted chat API.
  • Offline: once models are pulled locally, study turns do not need a cloud LLM endpoint.
  • Instructor-tunable: focused documents and study modes keep answers tied to the materials you choose, not a general web persona.

Limitations (from public README)

  • Requires local model runtime (Ollama and/or on-device backends) — not shipped in this page.
  • Embedding-backed retrieval needs a local embed model (e.g. nomic-embed-text).
  • Public macOS copy emphasizes PDF / Markdown / code; some media paths are exploratory.
  • Model capability differs by Gemma variant (text vs multimodal).
  • This simulation uses lexical retrieval, not sqlite-vec KNN.
