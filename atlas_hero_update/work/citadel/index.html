Architecture

Zero trust for AI agents

Zero trust means every agent action is untrusted until a gate proves it. The browser never holds cloud keys. Prompts reach a local model; host effects only happen after a rigid tool schema, a directory whitelist, and CLI traversal checks. Rate limits stop wallet-draining loops. Tools talk over stdio, not open ports. Memory and observations stay data, not authority— a file that contains a fake tool call must not become a new privileged command. Deny by default; allow only what the sandbox and allowlist explicitly permit.
